## Parsed public statements

The official site identifies the live service as WonderBane and distributes both `WonderbaneClient.zip` and `WonderBanePatcher.zip`. It links an official Discord for community discussion, patch notes, and support.

The homepage includes a character calculator described as mirroring server stat formulas. It publishes a twelve-rune maximum, a two-discipline maximum below level 70, and a three-discipline maximum at level 70 or above.

Its displayed stat derivation is described as race starting value plus class modifier, a five-point race boon, trained modifier, and all rune stat grants. Rune costs reduce the available pool, rune cap grants increase stat caps, and rune availability is filtered by race, base class, promotion, level, and current-stat requirements.

## Limitations

This snapshot establishes official service identity and published calculator behavior. It does not identify the server source commit, deployment power/effect rows, current patcher manifest, or whether every calculator output exactly matches the currently running server. Those require package fingerprints and controlled runtime comparisons.
